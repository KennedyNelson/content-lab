# Tool notes (2026-11-21)
- ffmpeg: installed, used for all audio/video mixing and encodes.
- Whisper: faster-whisper installs via pip but its model download (huggingface.co) is blocked in the sandbox. Use the local sherpa-onnx Whisper turbo model (/tmp/pp, rebuild if missing); its Hindi output often cuts off the end of short clips, so treat it as a rough check only.
- yt-dlp: installed, but YouTube is blocked by the sandbox proxy. Use the vidssave.com method in Chrome, or ask the owner for the file.
- HyperFrames (HeyGen, Apache 2.0): `npm i hyperframes`, `npx hyperframes init <name> -e blank --resolution portrait --non-interactive --skip-transcribe`, render with `HYPERFRAMES_SKIP_SKILLS=1 PUPPETEER_EXECUTABLE_PATH=/opt/pw-browsers/chromium_headless_shell-1243/chrome-headless-shell-linux64/chrome-headless-shell npx hyperframes render . -q draft -o out.mp4`. Do NOT use the full chromium (2 s clip took 2m43s); with the headless shell the same clip took 4.3 s.
- Remotion: rig in the kalujokesIG project (remotion/); render with --browser-executable and --concurrency=2.
- Video effects pack (55 effects, captions, pause trim): studio/effects/, decision guide studio/EFFECTS-GUIDE.md, licences studio/ASSETS.md. Added 2026-11-21; install not yet tested here.
- Design kit (PNG/PDF images, banners, flyers, pamphlets from HTML templates): studio/design/README.md, render.mjs. Motion libraries and GSAP/video-shotcraft skills: studio/MOTION-GUIDE.md.
- Git push (2026-11-22): if the session's git proxy refuses KennedyNelson/content-lab (only the old name is authorised), push with `git push https://github.com/KennedyNelson/funwithken-videos main`; GitHub's rename redirect lands it on content-lab. Raw URLs may 404 for about a minute after the push.
- kp.js standing characters: `kpSeated({...KALU, stand: 1})` lifts the body 205*s and straightens the legs (feet at y + 245*s); arm IK must use hip y - 205*s (see ep-shrink.js `ik`).
- Composio scrapecreators (2026-11-23): works on the Composio instant account (about $0.001 per call, no own wallet needed). SCRAPECREATORS_SEARCH_YOUTUBE with sort_by popular + content_type shorts returns results; adding upload_date (this_week/this_month) returned EMPTY lists, so leave the date filter off.
- Episode timing helper (2026-11-24): `wt(word, line)` returns the FIRST matching word of a line; when a word repeats in a line ("right now... right eye") pass a start time (`wt('right', 1, T_LEFT + .2)`, see ep-eyes.js). Clamp insert-local time with `Math.max(0, t - start)` when an insert starts a little before its line (a negative index crashed the render).
- Render timings (2026-11-24): render.mjs `video` at 30 fps took about 80 s for a 38 s short; the step-8 re-encode with `-preset slow` takes over 2 minutes, so run it with a 10-minute timeout.
